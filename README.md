# 💻 Code Roguelike

Um jogo **Roguelike com temática de programação**, desenvolvido em Python utilizando a biblioteca Pygame.

## 🎮 Sobre o projeto

A proposta deste projeto é desenvolver um jogo no estilo Roguelike em que o universo da programação é o tema principal.

Os jogadores poderão explorar um mundo inspirado na tecnologia, enfrentando inimigos que representam conceitos e elementos do desenvolvimento de software, como bugs, vírus e compiladores corrompidos.

Além disso, cada personagem será inspirado em uma linguagem de programação, trazendo características e atributos próprios para o sistema de combate.

## ⚔️ Personagens

As linguagens de programação serão representadas por diferentes classes de personagens:

- 🐍 **Python** — Guerreiro
- ☕ **Java** — Mago
- 🌐 **JavaScript** — Ladino
- 🛡️ **C#** — Paladino

Cada personagem possui atributos próprios, como vida, ataque, defesa e velocidade.

## 👾 Inimigos

O mundo do jogo contará com inimigos inspirados no universo da programação, incluindo:

- Slime de Código
- Inseto Bugado
- Aranha de Sintaxe
- Goblin de Sintaxe
- Golem de Código
- Doppelganger
- Vírus Corrompido
- Dragão de Código
- Compilador Corrompido
- Bug Original

Cada inimigo poderá apresentar comportamentos e estratégias diferentes durante os combates.

## 🛠️ Tecnologias utilizadas

- **Python** — Linguagem principal do projeto.
- **Pygame** — Biblioteca utilizada para desenvolver a interface gráfica, movimentação e mecânicas do jogo.

## 🎯 Objetivos do projeto

- Desenvolver um jogo Roguelike com temática de programação.
- Aplicar conceitos de Programação Orientada a Objetos.
- Trabalhar com classes, herança e polimorfismo.
- Desenvolver um sistema de combate por turnos.
- Implementar diferentes comportamentos para personagens e inimigos.
- Aprimorar conhecimentos em Python e Pygame.
